# Return Policy: Fashion and Footwear

## Return window
Clothing, footwear and fashion accessories can be returned within 15 days of delivery. The product must be unworn, unwashed and have all original tags attached.

## Size exchange
Size exchange is free once per order item. A second exchange for the same item is chargeable at Rs 99.

## Non-returnable items
Innerwear, socks, swimwear, and personalised or custom-made items are not eligible for return for hygiene reasons.

## Wrong or damaged item
If you receive the wrong size, wrong colour or a damaged item, report it within 48 hours of delivery with photos. Pickup and replacement are free.
